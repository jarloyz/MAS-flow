# Board

> The task flow of the workspace. Each card: `- [<ID>] <title> · cap: <CAP-ID> · track: <fast|standard|full|?> · <link to plan/doc>`.
> Cards move: Inbox → Ready → In Progress → Done (or Blocked). **WIP limit: 1 in progress** (the story in `handoff.md`).
> Who moves cards: planner/documenter add to Inbox; the Human prioritizes Inbox → Ready; the orchestrator moves Ready/Inbox → In Progress when a story starts and → Blocked when stuck; the documenter moves to Done in Phase 6.
> A goal too big for one story is an epic: the planner writes the first story and adds the rest to Ready with `· epic: <name>`.
> Start a card with `/masflow <ID or title>`.
